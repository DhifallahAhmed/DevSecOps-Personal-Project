Secure Todo App is a full-stack personal project that demonstrates modern DevSecOps practices using:

- Spring Boot for the backend (REST API)

- Svelte for the frontend (lightweight, reactive UI)

- MongoDB/H2 as the data store

- Docker and GitHub Actions CI/CD

- Netlify for frontend deployment

- Render for backend deployment

- Trivy for vulnerability scanning

- OWASP security configurations

- ELK stack for centralized logging & monitoring

The app lets users manage a simple todo list with real-time validation and backend persistence, while enforcing secure coding and deployment practices.
